# Schema Types Overview Reference

Structured data is machine-readable markup you add to a page that tells search engines and AI systems exactly what the page is about: a product, an article, a local business, a recipe, a person. Using the right schema type, with accurate properties, helps engines understand and represent your content, and can earn richer search results. The rule that governs all of it is simple: mark up only what is genuinely on the page, with the most specific type that fits.

This reference covers how to choose and apply schema types without inviting penalties.
