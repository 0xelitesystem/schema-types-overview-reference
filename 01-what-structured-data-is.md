# What structured data is

Structured data is a way of labeling the content of a page so machines can understand it precisely, rather than inferring meaning from the text alone. A page about a product contains a name, a price, and a rating, but to a machine reading the raw page, those are just words among other words. Structured data marks them explicitly: this is the product name, this is the price, this is the rating. Search engines and AI systems use these labels to understand the page accurately and to represent it well.

## A shared vocabulary

Structured data uses a shared vocabulary, a standard set of types and properties that engines recognize, so that marking something as a product or an article means the same thing everywhere. This common vocabulary, maintained as an open standard, defines types like product, article, recipe, event, person, and organization, each with properties appropriate to it. By using the agreed labels, you communicate with every engine that understands the standard, rather than inventing your own scheme that nothing recognizes. The value is in speaking the language the engines already read.

## How it is added to a page

The common way to add structured data is as a block of markup, typically written as a structured block placed in the page, that describes the content using the standard vocabulary. It sits alongside the visible content and is read by machines rather than shown to users. The recommended format expresses the data as a self-contained block, which keeps the markup separate from the page's display and easy to maintain. The user sees the normal page; the engine additionally reads the structured block that tells it precisely what the page contains.

## Why engines use it

Engines use structured data because it removes guesswork. Without it, an engine has to infer what a page is about from its text and layout, which is imperfect and can be wrong. With it, the engine knows directly: this page is a recipe with these ingredients and this cook time, this page is a local business with this address and these hours. This precise understanding lets engines represent the content better, sometimes as a rich result with extra detail shown directly in search, and increasingly lets AI systems extract and cite the content accurately. Helping engines understand the page is the whole point.

## What it can and cannot do

Structured data helps engines understand and potentially present your content more richly, and it supports being found and cited accurately. It does not, on its own, guarantee higher ranking or a rich result, since engines decide when to use the data and how. And it cannot make a page appear to be something it is not: the markup must reflect the actual content, or it misleads, which engines penalize. Structured data is a way to describe what is truly on the page so machines get it right; it is an accuracy aid, not a ranking trick, and treating it as the latter leads to the mistakes the later pages warn against.
